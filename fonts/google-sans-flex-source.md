- Request: https://fonts.googleapis.com/css2?family=Google+Sans+Flex:opsz,wght@144,500&text=SuperPower&display=swap
- Google Fonts version: v23. TrueType format, weight 500, optical size 144.
- Contains only the characters needed for `SuperPower`. Use only for the members-page footer wordmark.
- Font source family matches Antigravity's Google Sans Flex web typography. Its footer logo is custom SVG outlines; this typesets our own team name rather than copying those outlines.
